# PulseFit Studio Python

FastAPI + SQLite + Jinja + Tailwind implementation for a fitness studio management app.

## Run
```powershell
cd D:\TOOL_VID\gym-manager-python
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8100 --reload
```

Open:
```text
http://127.0.0.1:8100
```
